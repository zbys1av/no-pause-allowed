# Smart Video Cutter 1.1 — Portable

**Windows 10/11 x64. Extract the entire folder and run `SmartVideoCutter.exe`.**

Python, Qt and FFmpeg are included. No installation, administrator account,
registration or Internet connection is required. Keep `_internal` and `tools`
next to the EXE. See `PORTABLE-README.txt` for a short guide.

New in 1.1: analysis remaining-time estimate, a visible drop zone and file drops
on the player, source movement/still-time statistics, and finer cursor/brush
protection with less aggressive pause removal. Defaults: 95% sensitivity,
3-second minimum pause, 0.6-second padding, 8 samples/s and 960 px detail.

[Download ready-to-run ZIP](https://github.com/zbys1av/no-pause-allowed/archive/refs/heads/portable-windows.zip)

[Source code and detailed documentation](https://github.com/zbys1av/no-pause-allowed/tree/main)

Build provenance: `BUILD-INFO.json`. Packaged self-test: `portable-check.json`.
Tested under Wine; native Windows hardware and physical speakers were not tested.
